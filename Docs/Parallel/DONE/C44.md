## 1. 🔴 먼저 찾은 것 — **요청-35 가 미처리이고 상태가 어긋나 있다**

내가 `C43` 에서 타일 `PPU 1024 → 2048`(1.0 → 0.5유닛)로 바꾸고
**씬 `Grid.Cell Size` 를 `0.5` 로 같이 바꿔 달라**고 넘겼는데, 확인하니 **아직 `1, 1, 0`** 이다.

```
Sprites/Tiles/*.png.meta   spritePixelsToUnits: 2048   ← 커밋됨
SampleScene.unity  Grid    m_CellSize {x: 1, y: 1}     ← 그대로
```

🔴 **임포트가 한 번이라도 돌았으면 칸마다 절반이 비어 있다.** `D65`~`D76` 동안 에디터를 계속 썼다.

⇒ 요청 §0 에 **되돌리는 길까지 같이 줬다** — *"셀을 0.5 로 바꾸거나, 못 하겠으면 말만 해 줘.
내가 PPU 를 2048 → 1024 로 되돌린다."*

🔑 **사용자 요구(*"타일이 크다"*)보다 바닥이 안 깨져 있는 게 먼저다.**
마감이 이틀이라 **개선을 포기하는 선택지를 내가 먼저 제시했다.**

## 2. ✅ Ogre 를 화면에 내보냈다 — 안 A

`D65` 가 사용자 답(*"오거 자체를 못 봄"*)을 파고 원인을 찾았다 —
Ogre 가 `Elite2` 의 `EliteOverride` **한 군데**에만 있어서
`D51` 이 만든 새 행동 **`Blocker` 가 화면에 거의 안 나온다.**

| 웨이브 | 넣은 것 | 실제 소환 |
|---|---|---|
| `Normal3` | `Ogre*3@12:45-90` | 3마리 |
| `Elite1` | `Ogre*2@15:40-85` | 2마리 |

**안 B(행동을 Zombie 로 옮기기)를 안 골랐다** — Zombie 는 **유일한 `Chaser` 대조군**이다.
그게 없으면 *"다른 넷이 정말 다른가"* 를 대볼 기준이 사라진다.
🔑 **대조군을 소비해서 문제를 푸는 건 마지막 수단이다.**

**수를 적게 잡았다.** 목적이 *"난이도를 올리는 것"* 이 아니라 *"행동이 보이는 것"* 이다.
Ogre 는 `MoveSpeed 1.2` · HP 220(9층 ×1.9 = 418)이라 **오래 서 있어서** 3마리면 계속 화면에 남는다.

## 3. ✅ `Pickup_Swift` — 🟡 한 번 다시 그렸다

`D68` 이 급히 넣으면서 **`Pickup_Haste` 를 복제하고 색만 연두로** 물들여서
**공속 픽업과 모양이 같았다.** `C33`(탄환)과 같은 문제고 답도 같다 — **색이 아니라 모양으로 가른다.**

| | |
|---|---|
| 규격 | 1024² · `PPU 2048` · Point · **색 5개** — 기존 픽업 6장을 재서 맞췄다 |
| 모양 | **빨리감기 꺾쇠(»)**. Haste 가 **세로 지그재그 번개**라 **주축을 90도 틀었다** |
| 색 | **중립(흰~회색)** — 프리팹이 연두로 곱한다. 여기서 초록으로 칠하면 **두 번 곱해져 형광**이 된다 |

🟡 **첫 판은 날개 부츠였는데 아래 화살표로 읽혔다.** 32×32 에서 날개와 부츠가 한 덩어리로 뭉쳤고,
게다가 **아래 방향은 "느려짐"** 으로 보인다.

🔑 **작게 만들면 디테일이 아니라 실루엣만 남는다.** `C33` 에서 예광탄을 두 번 그린 것과 같은 자리다 —
그때는 *"길쭉하다 ≠ 방향이 있다"* 였고, 이번엔 *"부품 두 개 = 덩어리 하나"* 였다.
