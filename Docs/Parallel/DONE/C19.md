## 4. CSV 3파일

| 파일 | 넣은 것 |
|---|---|
| `Weapons.csv` | `SummonDragon` · `SummonOctopus` 2줄 (**12열 유지**) |
| `Items.csv` | 같은 Id 2줄 (**8열**) · 가격 12 / 11 |
| `SceneWiring.csv` | `LevelUpManager,allItems` **22 → 24** |

**열을 새로 만들지 않고 재해석했다.** `SummonWeapon` 의 Ring 모드는
`Damage`·`Cooldown`·`Range` **셋만** 읽는다 — `ProjectileSize`·`ProjectileCount` 는
진짜로 안 쓰인다. Ranged 모드는 `TravelPrefab`·`ProjectileSpeed`·`ProjectilePrefab`·
`ProjectileSize`(×`explosionRadius`)·`Range`(탐색 반경)를 쓴다.

**드래곤 `Range` 7~9 는 파이어볼(12~14)보다 일부러 좁다** — 화면 반높이가 6이라
12 면 화면 밖 적을 저격하는 터렛이 된다. `ProjectileSize` ≤1 인 것도 사용자가
**"소규모 폭발"** 이라고 못 박았기 때문이다.

**기계적 검증:** 열 수 · Id 중복 없음 · 모든 `Items.Weapon` RefId 가 `Weapons.csv` 에 있음 ·
배열 길이 전부 5 · DPS 사다리(용 6.4→42.5, 문어 5.8→32.5)가 형제 무기와 어긋나지 않음.

## 5. SFX 볼륨 2값 — **점유율**이라는 자를 새로 썼다

**점유율 = 클립 길이 ÷ 최소 쿨다운** = 한 판에서 그 소리가 들리는 시간의 비율.

**검 클립 길이는 못 늘린다.** D14 실측 연타 간격 0.249s 가 상한(0.247s)이라

## 7. 이번에 배운 것

🔑 **"A 가 B 의 9배"라는 관찰이 곧 "A 를 줄여라"가 아니다.**
같은 자(잉크 밀도)로 형제 애셋과 대 보니 촉수는 정상이었고, 범인은
아무도 안 보던 **중앙 장식**이었다. 관찰은 받되 **원인은 다시 재는 게 맞다.**

🔑 **`sprite.bounds` 로 그림 크기를 재면 안 된다.** 셀 사각형 기준이라
소환수든 오우거든 **0.500** 이 나온다. **알파 바운딩 박스**로 재야 한다.
