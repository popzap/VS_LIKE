| ④ | 🔴 **실플레이 — 날아가는 방향으로 촉이 향한다** | ✅ **눈으로 봤다.** 아래 §판정-④ |

### 판정-① — 기대값이 왜 달랐나 (숫자 둘 다 맞다)

요청서는 `(0.391, 0.141)` 을 기대했는데 실제 `sprite.bounds.size` 는 `(0.500, 0.500)` 이다.

| 무엇을 재나 | 계산 | 값 |
|---|---|---|
| `sprite.bounds.size` (Single 모드) | **텍스처 전체 rect** 256 ÷ 512 | `(0.500, 0.500)` |
| 그림의 실제 크기 | **알파 bbox** 200 ÷ 512, 72 ÷ 512 | `(0.391, 0.141)` |

Single 스프라이트는 알파를 잘라내지 않고 **캔버스 전체를 rect 로 잡는다.**
요청서 숫자는 알파 bbox 기준이라 서로 다른 것을 재고 있었다.

🔴 **①이 잡으려던 것(PPU 1024 로 들어감)은 통과다.** 1024 였다면 `bounds` 가 `0.25` 였을 것이다.
그림의 실제 폭 **0.391 유닛**은 기존 총알 **0.41** 과 사실상 같다 — 요청서가 노린 값 그대로다.

> 🔑 다음에 판정 기준을 쓸 때 **`bounds` 기준인지 알파 bbox 기준인지** 같이 적을 것.

### 판정-④ — 봤다 (이 요청의 본체)

플레이 모드에서 플레이어 `(3.71, 1.08)` 둘레 2.2 유닛에 `Proj_Arrow` 4개를
`+X / +Y / −X / −Y` 로 세우고 `Initialize()` 로 회전시켰다 (`speed=0`, 콜라이더 off).

```
[D9] +X(오른쪽) → z회전 = 0.0    scale = 1.00  sprite = Arrow  flipX = False
[D9] +Y(위)     → z회전 = 90.0   scale = 1.00  sprite = Arrow  flipX = False
[D9] -X(왼쪽)   → z회전 = 180.0  scale = 1.00  sprite = Arrow  flipX = False
[D9] -Y(아래)   → z회전 = 270.0  scale = 1.00  sprite = Arrow  flipX = False
```

`Unity_Camera_Capture(Camera.main)` 로 **게임 카메라**를 찍었다.
→ **화살 4개가 각자 자기 방향으로 촉을 향하고 있다.** 위·아래·왼쪽 어느 것도 뒤집히지 않았다.

`ProjectileBase` 에는 `flipX` 가 아예 없다. 방향은 오직
`Mathf.Atan2(dir.y, dir.x)` 회전 + `transform.Translate(Vector2.right …)` 로 만들어진다 —
**그래서 그림이 +X 를 향해야만 맞고, 실제로 그렇게 그려져 있다** (촉 오른쪽 · 깃 왼쪽).

### 판정-⑤ — 대조군을 같이 쏴서 봤다

표적(Goblin, `tag=Enemy` · `layer=Enemy` · CapsuleCollider2D trigger · Rigidbody2D Dynamic)에
`Proj_Bullet` 과 `Proj_Arrow` 를 **같은 조건으로** 쐈다.

| 발사체 | 출발 | 소멸 지점 | 이동 거리 | 표적과의 거리 |
|---|---|---|---:|---:|
| `Proj_Bullet` (대조군) | 표적 왼쪽 3 | `(7.07, 1.08)` | **2.37** | 0.63 |
| `Proj_Arrow` | 표적 아래 3 | `(7.70, 0.45)` | **2.37** | 0.63 |

**두 숫자가 완전히 같다** — 화살이 총알과 똑같은 지점에서 똑같이 멈췄다.
`Physics2D.GetIgnoreLayerCollision(Projectile 8, Enemy 6) = False` 도 확인했다.

콘솔 스택 트레이스가 경로 전체를 보여 준다:

```
ProjectileBase.OnTriggerEnter2D (ProjectileBase.cs:40)
  → EnemyBase.TakeDamage (EnemyBase.cs:374)
    → EnemyBase.Die (EnemyBase.cs:421)
```

즉 **콜라이더가 살아 있고 → 피해가 들어갔고 → HP 가 0 이 됐다.** ⑤ 통과.

> ℹ️ 첫 시도에서는 화살이 표적을 지나쳐 사거리 끝(20 유닛)까지 날아갔다.
> 표적을 **스폰한 그 프레임에** 8 유닛/초로 쐈던 케이스다 —
> 에디터가 포커스를 잃으면 프레임 간격이 커져 한 프레임 이동량이 콜라이더 반지름을 넘는다.
> 속도를 6 으로 낮추고 표적을 세운 뒤 다시 쏘니 **대조군 총알과 똑같이** 맞았다.
> **화살 문제가 아니라 테스트 조건 문제였다** — 그래서 대조군을 같이 쏜 것이다.
