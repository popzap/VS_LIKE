# D30 — 메타 강화 화면: 재화 고리를 닫았다 (DEV, 2026-09-03)

## 1. 없던 것은 백엔드가 아니라 **화면**이었다

읽어 보니 `MetaProgressionManager` 는 **이미 완성돼 있었다** — `PurchaseUpgrade`,
`GetUpgradeLevel`, `GetStatBonus`, JSON 저장/로드까지. `PlayerStats.cs:228` 도
`GetStatBonus()` 를 **이미 부르고 있었다.**

없던 건 셋뿐이다:

| 없던 것 | 왜 |
|---|---|
| `UpgradeDefinition` **애셋 0개** | 🔴 클래스가 `MetaProgressionManager.cs:51` 안에 있어 `I-19` 함정에 걸려 있었다 |
| **화면** | `GameState.MetaScreen` 은 enum 에만 있고 전환 코드가 0개였다 |
| **진입점** | 메인 메뉴에 버튼이 없었다 |

⇒ 메타 골드는 **벌기만 하고 쓸 데가 없었다.** 죽으면 아무것도 안 남는 상태.

## 2. 순서가 전부였다 — `I-19` 를 먼저 풀지 않으면 되돌릴 수 없다

`CLAUDE.md` §3 이 못박은 그대로다. `ScriptableObject` 클래스가 다른 파일에 얹혀 있으면
새 `.asset` 의 `m_Script` 가 **`0` 으로 기록되고 재임포트로도 복구되지 않는다.**
애셋이 0개였던 덕에 아직 아무도 안 다쳤을 뿐이고, **만드는 순간 터질 자리**였다
(`REQ/DEV.md` 요청-20 §3-가 에서 CONTENT 가 미리 짚었다).

그래서 1단계가 파일 분리였다. 결과:

```
UpArmor.asset   m_Script: {fileID: 11500000, guid: 03c86aaa1fa60f94f8d23dbdd777603d, type: 3}
… 7개 전부 동일 guid = UpgradeDefinition.cs 의 guid
```

**`0` 이 하나도 없다.** 먼저 했기 때문에 그렇다.

## 3. 값은 CSV 로 갔다 — 인스펙터가 아니라

`CLAUDE.md` §2 는 *"CSV 가 원본이다. 인스펙터에서 SO 를 직접 고치지 말 것"* 이다.
`Costs`·`Bonus` 가 배열이라 예외를 둘까 했지만, `CsvTable.ArraySeparator`(`|`)와
`CsvRow.Ints`/`Floats` 가 **이미 있어서** 예외가 필요 없었다 (사용자 판단).

| 파일 | 무엇 |
|---|---|
| `Assets/Game/Balance/Upgrades.csv` | 신규 · 7항목 · `Costs`·`Bonus` 는 `\|` 구분 |
| `BalanceImporter.ImportUpgrades` | 신규 · 1차 임포트(참조 없는 표)에 넣었다 |
| `BalanceImporter` Export | `Upgrades.csv` 회수 경로도 같이 넣었다 |

### 🔴 임포터가 `StatKey` 오타를 잡는다

`MetaProgressionManager.ApplyStatKey` 의 `switch` 는 모르는 키를 **조용히 무시**한다 —
강화를 사도 아무 일이 안 일어나고 예외도 경고도 없다. **임포터가 안 잡으면 아무도 못 잡는다.**
그래서 `IsKnownStatKey` 를 두고 Import 로그에 `!` 줄을 찍게 했다.
`Costs`/`Bonus` 길이가 `MaxLevel` 보다 짧은 것도 같이 본다.

## 4. 🔴 새 폴더를 만드는 임포터에서만 터지는 버그를 밟았다

첫 Import 뒤 `Assets/Game/` 에 **`UpgradeData 1` ~ `UpgradeData 6`** 이 생겼다.

원인은 `EnsureFolder` 다:

```csharp
if (AssetDatabase.IsValidFolder(folder)) return;   // ← 이것만 봤다
```

`StartAssetEditing()` 구간에서는 AssetDatabase 가 갱신되지 않아 **방금 만든 폴더를 아직
"없다"고 답한다.** 그래서 행마다 `CreateFolder` 가 다시 돌고 Unity 가 이름을 비켜 준다.

🔑 **기존 폴더들은 전부 이미 디스크에 있어서 이 버그가 여태 안 드러났다.**
새 폴더를 처음 만드는 임포터는 `Upgrades` 가 처음이었다.

고친 방법은 디스크를 같이 보는 것이다 — `CreateFolder` 는 파일시스템에 즉시 반영한다:

```csharp
if (AssetDatabase.IsValidFolder(folder))  return;
if (System.IO.Directory.Exists(folder))   return;   // 추가
```

Import 재실행으로 **중복 0개**를 확인했다. 빈 폴더 6개와 그 `.meta` 는 지웠다.

## 5. 화면 — 기존 것을 복제해서 만들었다

새로 그리지 않았다. 폰트·색·앵커·`CanvasScaler` 를 그대로 물려받는 게 안전하다.

| 만든 것 | 원본 |
|---|---|
| `Prefab_UpgradeCard` | `Prefab_ShopCard` (카테고리 부품 제거, `SoldOut`→`Maxed`) |
| `MetaScreenPanel` | `MainMenuPanel` (버튼 2개 제거, `StartButton`→`BackButton`) |
| `MetaButton` | `MainMenuPanel/StartButton` |

🔴 **복제 버튼의 `onClick` 을 반드시 비워야 한다.** `StartButton` 복제본은
`OnStartClicked` 를 그대로 갖고 있어서, 안 지우면 **Upgrades 를 눌렀는데 런이 시작된다.**
`GetPersistentEventCount() == 0` 으로 확인했다.

### 레이아웃은 한 번 틀렸고 캡처로 잡았다

첫 캡처에서 설명·가격·버튼이 셀 밖으로 흘렀다. 셀을 250×**220** 으로 잡았는데
카드 원본이 250×**440** 이었기 때문이다 — `GridLayoutGroup` 이 카드 `RectTransform` 만
줄이고 자식들은 위쪽 기준 고정 오프셋이라 아래가 잘린다.

강화에는 아직 아이콘이 없어 상점 카드의 위쪽 공간이 통째로 비므로
**카드를 250×320 으로 압축**하고 셀을 같은 값으로 맞췄다.

> ⚠️ **UI 는 카메라 캡처로 못 본다.** Canvas 가 `ScreenSpaceOverlay` 라
> `Unity_Camera_Capture` 는 씬 뷰만 찍는다. `ScreenCapture.CaptureScreenshot` 을 쓸 것.
