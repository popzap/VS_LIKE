수치 대조는 **전부 통과**했다 — `layerSpawnGrowth 0.17` · `maxAliveCeiling 360` ·

|---|---|
| `BALANCE.md:1279` | `최대 지출 (1.2회 × 3칸 × 평균 75G + 리롤) ≈ 400G` |

- `D69` — 가격이 **층·레벨 스케일**이 됐다 (0층 `0.6배` ~ 8층 `약 3.5배`)

⇒ **배수구가 대략 3배다.** 즉 *"골드가 막혀서 절반 넘게 소멸한다"* 는 **진단 자체가 낡았다.**

🔑 **CSV 는 맞는데 문서만 틀린 종류의 오류다.** 값 대조로는 절대 안 잡힌다 —
값은 전부 일치했다. **결론 문장을 따로 읽어야** 나온다.
`C42` 의 *"무기 사거리 3.5~6"* 과 같은 계열이다: 한 번 적은 뒤 근거가 바뀌었는데
문장만 살아남았다.

🟡 **새 숫자를 못 박지 않았다.** 실측 `M` 이 없기 때문이다 —
`D61` 의 세 판(`M` 89 / 1168 / 465)은 Dev 패널 층 스킵이 섞여 오염됐다(`D63`).
