## 1. 🔴 되돌리려던 참이었다 — **내가 재는 곳이 틀렸다**

`D79` 가 내 `Tiles/*.asset` 의 `m_Color` 를 바꿨길래 재 봤다:

```
층0 0.1499 · 층9 0.1498  →  dL 0.0001
```

**`C37` 이전과 같은 숫자다.** *"내 층 구분이 통째로 사라졌다"* 로 읽고
`retint_tiles.py` 를 다시 돌리려던 참이었다.

그런데 `BOARD` 의 `D79` 줄을 읽고 **`Tilemap.color` 라는 새 손잡이가 생긴 걸** 알았다.
넣고 다시 쟀다:

| | dL | 층0 편차 | 층9 편차 |
|---|---:|---:|---:|
| `C37` 내 램프 | 0.0443 | 0.0138 | 0.0205 |
| **`D79`** | **0.0468** | **0.0001** | **0.0001** |

🟢 **두 축 모두 낫다. 되돌릴 게 없었다.**

### 🔑 왜 더 나은가 — 내가 절충하던 것을 없앴다

`D79` 의 진단: *"`C37` 램프는 **층 안의 균일함**과 **층 사이의 차이**를
**같은 손잡이**로 조절해 서로를 깎고 있었다."*

맞다. 나는 `C39` 에서 **감마로 절충**했다 — γ1.6 을 고르며
*"구분 0.009 를 내주고 퀼트를 36 % 줄였다"* 고 적었다.
`D79` 는 **타일은 한 점(편차 0) · 층 구분은 `Tilemap.color`** 로 갈라
**트레이드 자체를 없앴다.**

⇒ **절충하고 있었다는 것 자체가 "축이 하나로 묶여 있다"는 신호였다.**

### 🔴 내 실수의 모양이 늘 같다

`C37` 에서 *"손잡이는 PNG 가 아니라 `m_Color` 였다"* 를 찾아 놓고,
이번엔 **`m_Color` 만 재고 새 손잡이를 안 봤다.**

`D53` 이 남긴 말 그대로다 — **측정이 회귀를 말할 때 먼저 의심할 것은 측정이다.**
`C36`(내 정규식이 배열을 못 읽음) · `C38`(최댓값 vs 평균) · `C39`(밝기 공식) ·
`C41`(Ultra/Medium) 에서 **남의 숫자를 네 번 되물었는데**, 이번엔 내 숫자였다.

## 2. ✅ `Regeneration` 아이콘

`D74` 가 `HpRegen` 패시브를 넣으며 **`MaxHp.png`(빨간 하트)를 그대로** 썼다 —
**최대 체력과 그림이 같아서** 레벨업 카드에서 못 가른다.

| | MaxHp | **HpRegen** |
|---|---|---|
| 실루엣 | 아래가 뾰족한 **하트** | **둥근 고리**(회전 화살표) |
| 색 | 빨강 | **초록** |
| 뜻 | 체력 총량 | 회전 = 되돌아온다 · 십자 = 치유 |

🔑 **실루엣과 색을 둘 다 갈랐다.** 색만 바꾸면 색약에서 무너지고,
실루엣만 바꾸면 카드에서 눈에 덜 띈다. `C33`(탄환)·`C46`(Swift)과 같은 판단이고
**세 번 다 "같은 그림을 색만 바꿔 쓴 것"이 원인이었다.**

🟡 **한 번 다시 그렸다** — 처음엔 고리를 두 군데 끊고 화살촉을 둘 달았는데
64px 에서 촉이 부서져 **한쪽이 노이즈 조각**으로 보였다.
**호 하나 + 촉 하나**("새로고침" 기호)로 줄이니 작아져도 뜻이 안 흐려진다.

## 3. ✅ `.meta` 를 **내가 먼저 맞췄다**

`C46` 에서 *"새 애셋은 `.meta` 까지가 납품물"* 을 **세 번째로** 겪었다
(`C28` 걷기 PPU · `C33` 9-slice border · `C46` 픽업 전 항목).

이번엔 파일을 만들자마자 `MaxHp.png.meta` 를 복제해 넣었다 —
`PPU 512 · Point · Single · 압축 0`. **기존 패시브 11장과 한 글자도 다르지 않다.**

⚠️ 다만 **손으로 만든 `.meta` 는 처음**이라 `spriteID`·`internalIDToNameTable` 은 비워 뒀다.
임포트 후 정상으로 채워지는지 확인해 달라고 판정 ③에 넣었다.

🔑 **적어서 넘기는 것보다 맞춰서 넘기는 게 싸다** — `C46` 에서 얻은 것을 바로 썼다.
