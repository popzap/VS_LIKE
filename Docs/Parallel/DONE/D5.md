# D5 — 일시정지·옵션창 한글 6곳 영문화 (DEV)

> 2026-08-30 · 병렬 세션 DEV · [`BUGS.md` B4](../BUGS.md) 처리

## 왜 했나

B4. 일시정지·옵션 패널의 글자 6곳이 **빈칸**으로 나왔다.
원인은 CONTENT 가 확정했다 — 씬에 한글이 남아 있는데 폰트 `Pretendard SDF` 는
23차(I-60)부터 **Static · 115자**(ASCII 32~126 + 기호 20)라 한글 글리프가 없다.

**폰트를 다시 굽지 않고 영문화한다**(사용자 결정). 6개 단어를 위해 한글을 넣으면
I-60 이 55MB → 4.8MB 로 줄인 아틀라스가 도로 커진다.
`.unity` 는 DEV 소유라 이 작업이 이쪽으로 왔다.

## 🔴 걸려 넘어진 것 — 플레이 모드에서는 씬을 저장할 수 없다

첫 실행은 치환까지 `changed = 6 / 6` 으로 성공했는데 저장에서 터졌다.

```
System.InvalidOperationException: This cannot be used during play mode
  at UnityEditor.SceneManagement.EditorSceneManager.MarkSceneDirty
```

**D4 끝에 내가 껐던 플레이 모드를 그 사이에 사용자가 다시 켜 놓은 상태였다.**
플레이 모드에서 한 씬 변경은 플레이를 끄면 **전부 되돌아간다** — 디스크에는 아무것도 안 남는다
(`git status --short Assets/Scenes/` 가 빈 출력인 것으로 확인).

임의로 끄지 않고 사용자에게 물어 승인을 받은 뒤 `Stop` → 재실행했다.
그 뒤로 스크립트 맨 앞에 가드를 넣었다:

```csharp
if (EditorApplication.isPlaying) { result.LogError("[D5] 아직 플레이 모드다. 중단한다."); return; }
```

## 검증 — 판정 기준 5개

| # | 기준 | 결과 |
|---|---|---|
| ① | 6곳이 영문 | 전부 `ascii=True` ✅ |
| ② | 폰트 문자표에 전부 있음 | `HasCharacters=True · missing=[]` ✅ |
| ③ | 실제로 글리프가 그려짐 | `ForceMeshUpdate` 후 `characterCount == visible` ✅ |
| ④ | 🔴 실플레이 육안 | 캡처 2장 ✅ |
| ⑤ | 🔴 폰트 경고 0건 | 플레이 전체 로그 **7건 전부 `Log`** · Warning 0 · Error 0 ✅ |

③이 ②보다 강하다. 문자표에 있어도 렌더링 단계에서 빠질 수 있는데,
`ForceMeshUpdate` 뒤 `characterCount` 와 `isVisible` 개수가 6곳 모두 같았다 = **빈칸이 하나도 없다.**

```
[D5] [PAUSED]   font=Pretendard SDF  hasAll=True  missing=[]  chars=6 visible=6
[D5] [Continue] font=Pretendard SDF  hasAll=True  missing=[]  chars=8 visible=8
[D5] [Options]  font=Pretendard SDF  hasAll=True  missing=[]  chars=7 visible=7
[D5] [Quit]     font=Pretendard SDF  hasAll=True  missing=[]  chars=4 visible=4
[D5] [OPTIONS]  font=Pretendard SDF  hasAll=True  missing=[]  chars=7 visible=7
[D5] [CLOSE]    font=Pretendard SDF  hasAll=True  missing=[]  chars=5 visible=5
```

### ④ 실플레이 — 오버레이 캔버스는 카메라 캡처에 안 잡힌다

`UI Canvas` 는 **`ScreenSpaceOverlay`** 다. `Unity_Camera_Capture` 는 카메라를 렌더 타깃에
그리는 방식이라 **오버레이 UI 가 한 픽셀도 안 나온다** — 첫 캡처는 타일과 적만 찍혔다.

플레이 모드 한정으로 `renderMode` 를 `ScreenSpaceCamera` + `worldCamera = Camera.main` 로
바꿔서 찍었다. **플레이를 끄면 되돌아가므로 디스크에는 안 남는다** —
끝난 뒤 `git diff --stat` 이 여전히 `6 insertions(+), 6 deletions(-)` 인 것으로 확인했다.

두 장 다 글자가 또렷하게 읽혔다:

- 일시정지 — `PAUSED` / `Continue` / `Options` / `Quit`
- 옵션 — `OPTIONS` / `BGM` / `SFX` / `CLOSE`

### 웨이브까지 들어간 경로

`PauseMenuUI.Open()` 은 `CanPause(s) => s == GameState.Wave` 라 메인 메뉴에서는 그냥 return 한다.
`StartRun()` → `StageMapManager.SelectNode(Layers[0][0])` 로 Wave 에 들어간 뒤 열었다
(D4 와 같은 경로 — `RollStageType` 은 `layer == 0` 이면 항상 `Normal`).

## 검증하다 배운 것 (다음에 또 걸린다)

| 틀린 추측 | 실제 |
|---|---|
| MCP 호출 사이에는 프레임이 안 간다 | **간다.** `Open()` 을 부르고 다음 호출에서 봤더니 이미 `LevelUp` 으로 넘어가 패널이 닫혀 있었다. 상태를 고정하려면 `ManageEditor(Pause)` 로 에디터를 멈춰야 한다 (멈춰도 `Camera_Capture` 는 찍힌다) |
| 카메라 캡처면 UI 도 찍힌다 | 오버레이 캔버스는 **안 찍힌다.** 위 방법으로 우회한다 |
| `foreach (Transform child in parent)` 안에서 `SetAsLastSibling()` | 순회 중 순서가 바뀌어 **일부가 건너뛰어진다.** 실제로 끄려던 패널이 안 꺼졌다. 순회와 재정렬을 분리할 것 |
| bash `grep 'm_text:.*\\u'` 로 남은 한글 세기 | **오탐한다.** 고친 뒤인데 8을 반환했다. `grep -n 'm_text:' … \| grep 'u[0-9A-F]\{4\}'` 처럼 리터럴로 다시 걸러야 0줄이 나온다 |
