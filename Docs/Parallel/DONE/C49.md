## 3. 🔑 `B13`(Luck)과 같은 모양인데 **증상이 다르다**

`PlayerStats.cs:334` 의 DEV 주석이 그대로 가리킨다:

> *"`Luck`(줄곧 빠져 있었다 · `B13`)과 `HpRegen`(`D74` 에서 실측으로 잡았다)"*

**새 스탯 열을 넣을 때 소비처를 전부 안 고치면 조용히 빠진다.**

| | 어디서 빠졌나 | 증상 |
|---|---|---|
| `B13` Luck | **최종 스탯** | 효과가 **안 났다** |
| **이번** HpRegen | **도감 표시** | 🔴 **효과는 나는데 안 보인다** |

🔴 **두 번째가 더 안 잡힌다.** 효과가 안 나면 로그·수치로 드러나는데,
**표시만 빠지면 화면을 봐야만** 안다. 이번에도 **사용자 스크린샷**이 없었으면 못 봤다.

⚠️ 소비처 목록을 요청에 남겼다 —
`PassiveData`(배열+Get) · `PassiveEffect` · `StatBlock` · `PlayerStats` · **`CodexPanel`** · `Economy.csv`.

  내가 파일로는 못 닫는 항목이었는데 **사용자 화면 한 장으로 닫혔고**,
  덤으로 **내가 안 찾던 결함까지** 나왔다
