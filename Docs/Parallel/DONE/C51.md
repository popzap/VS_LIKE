## 5. 이번에 배운 것

🔑 **"쓸 곳이 없다" 와 "쓸 줄 모른다" 는 증상이 같다 — 잔고가 남는다.**
런 골드는 전자였고 고쳐졌다. 메타 골드는 **후자**인데 **같은 처방을 적어 뒀었다**(가격 인하).
잔고만 보고 처방을 쓰면 절반은 틀린다. **가르는 건 잔고가 아니라 잔고 ÷ 최저가**다 —
런 골드는 74 / 210 = **0.35배**(못 산다), 메타 골드는 1794 / 60 = **30배**(안 산다).

🔑 **로그 둘이 같은 병이었다.** 리롤 문구(`비용 누계`)도 `[Meta] Saved` 도
**동작만 적고 상태를 안 적는다.** 그래서 하나는 **오독을 만들었고**(`D96` 의 표),
하나는 **물음 자체를 막았다**(방문 시점 잔고). 둘 다 한 줄이면 고쳐진다.
⇒ **로그는 "무엇을 했나" 가 아니라 "그래서 지금 얼마인가" 를 적어야 한다.**
