# D8 — 소리 없던 트리거 6곳 배선 + 엘리트 사망음 (요청-3 / C3)

> 요청: [`REQ/DEV.md` §요청-3](../REQ/DEV.md) · 요청자 CONTENT(C3) · 처리 2026-08-30 (31차)

---

## 왜 했나

효과음 키가 있는 자리는 이미 다 울고 있었는데, **아예 키가 없어서 조용한 지점이 6곳** 있었다.
터렛이 쏴도 · 원거리 적이 쏴도 · 식당이 회복시켜도 · 보스가 나와도 · 리롤을 눌러도 소리가 없다.
CONTENT 는 스펙만 낼 수 있다 — **클립 생성은 Unity AI(에디터)** 이고
`AudioLibrary.asset` 등록도 `.asset` 이라 둘 다 DEV 소유다. 그래서 통째로 DEV 요청으로 왔다.

같이 들어온 사용자 결정: **잡몹은 전부 같은 사망음, 엘리트·보스만 다르게.**

## 1) `SfxId` 7개 추가 — 기존 값이 하나도 안 밀렸다

`AudioLibrary` 는 **배열 인덱스가 아니라 `Id` 값**으로 매핑한다
(`AudioLibrary.cs:70` `_sfxMap[e.Id] = e`). 그래서 분류별 **빈 번호에 끼워 넣어도 안전**하다.

| 값 | 이름 | 분류 |
|---:|---|---|
| `14` | `EnemyDieElite` | 전투 (엘리트·보스 공용) |
| `16` | `EnemyShoot` | 전투 |
| `17` | `Crit` | 전투 — ⚠️ **값만 예약.** 클립·호출 없음 |
| `24` | `Heal` | 픽업·성장 |
| `32` | `BuildingFire` | 건물·진행 (터렛·곡사포 공용) |
| `33` | `BossAppear` | 건물·진행 |
| `41` | `UiCancel` | UI |

`15` 는 **비워 뒀다** — 나중에 보스만 갈라야 할 때 `EnemyDieBoss` 자리다.
삽입 후 `WeaponFire=1` … `UiSelect=40` 이 전부 그대로인 것을 확인했다.

**`AudioId.cs:8` 의 주석도 같이 고쳤다** (요청서가 명시적으로 부탁한 항목).
`"새 항목은 끝에 추가한다"` 는 구현과 달랐다 — 실제 규칙은 *"기존 항목의 **값**을 바꾸지 말 것"* 이고,
빈 번호 삽입은 안전하다. 이 주석 때문에 CONTENT 도 한 번 잘못 판단했다.

## 2) 호출부 6곳

| 값 | 넣은 곳 | 비고 |
|---|---|---|
| `EnemyDieElite` | `EnemyBase.cs` 사망 처리 (`PlayDeathImpact()` 직후) | `Play(IsElite \|\| IsBoss ? EnemyDieElite : EnemyDie)` |
| `EnemyShoot` | `EnemyBase.FireProjectile()` 끝 | 탄이 **실제로 나간 뒤에만** 운다 — 앞의 조기 return 2개는 "쏘려다 못 쏜" 경우다 |
| `Heal` | 🔴 **`HealPickup.cs`** (`player.Heal()` 직후) | **요청서와 다른 위치다 — 아래 참조** |
| `BuildingFire` | `TurretBuilding.Attack()` · `BombardBuilding.Attack()` | 둘이 같은 키 |
| `BossAppear` | `WaveManager` 보스 소환 직후 1회 | 처치음이 아니다 |
| `UiCancel` | `ShopManager.Reroll()` · `LevelUpManager.OnRerollClicked()` | 구매·선택은 기존 `UiSelect` 유지 |

### 🔴 요청서와 다르게 한 것 — `Heal` 위치 (사용자 승인 완료)

요청서는 `RestaurantBuilding.OnCooldownElapsed()` 를 지목했는데,
**그 메서드는 회복을 안 한다.** 힐 픽업을 **떨어뜨릴** 뿐이고
실제 회복은 `HealPickup.cs:34` `player.Heal(_amount)` 다.

요청서 자신의 🔴 규칙(*"주기적인 건물 산출에 소리를 달면 잔소리가 된다 — Farm·Village 에
소리를 안 단 것과 같은 이유"*)을 그대로 적용하면 **떨굴 때가 아니라 주울 때** 울어야 한다.
주울 때는 플레이어가 밟아서 일어난 일이라 소리가 **정보**가 된다.
→ 사용자에게 알리고 승인받았다.

### 🔴 터렛이 `WeaponFire` 를 재사용하지 않은 이유

`AudioManager` 의 중복 컷이 **0.04초**다(`AudioManager.cs:44`, `AudioClip` 기준).
터렛과 플레이어가 같은 키를 쓰면 **터렛 소리가 플레이어 발사음을 잡아먹는다.**
내 무기가 나갔는지 모르게 된다. 그래서 `BuildingFire` 라는 별도 키다.

### 소리를 일부러 안 넣은 곳

- `Farm` · `Village` 산출 — 요청서 지시. 주기적이라 잔소리가 된다
- `BombardBuilding` 의 `bombPrefab == null` 대체 경로(`SpawnExplosion`) —
  `AoeProjectile.cs:45` 가 이미 `SfxId.Explosion` 을 울린다. 두 번 울면 안 된다

## 3) 클립 6개 생성 (`Crit` 제외)

`elevenlabs-sound-effects-v2` 로 생성 → **프로젝트 규격에 맞춰 재임포트**했다.

🔴 **Unity AI 의 `GenerateSound` 기본값은 Vorbis + 스테레오**인데
기존 SFX 14개는 전부 **ADPCM + `forceToMono`** 다. 그대로 두면 6개만 규격이 다르다.
`compressionFormat = ADPCM` · `forceToMono = true` 로 바꾸고 `SaveAndReimport()` 했다.

| 파일 | 길이 | Volume | PitchJitter | 근거 (요청서 표) |
|---|---:|---:|---:|---|
| `SFX_BuildingFire.wav` | 0.52s | 0.22 | 0.14 | 가장 반복적. 터렛 7채가 쉬지 않고 쏜다 |
| `SFX_EnemyShoot.wav` | 0.63s | 0.30 | 0.12 | `EnemyHit`(0.28) 급 |
| `SFX_UiCancel.wav` | 0.52s | 0.45 | 0.03 | `UiSelect`(0.55)보다 **일부러 낮게** |
| `SFX_Heal.wav` | 0.91s | 0.50 | 0.05 | 주기적이지만 드물다 |
| `SFX_EnemyDieElite.wav` | 1.23s | 0.75 | 0.04 | `EnemyDie`(0.40)보다 확실히 커야 한다 |
| `SFX_BossAppear.wav` | 2.51s | 0.95 | 0.00 | 게임에서 가장 큰 순간. `PlayerDie`(0.90) 위 |

`AudioLibrary.asset` 의 `sfx` 목록이 **14 → 20** 이 됐다.
`SerializedObject` 로 등록했고, 같은 `Id` 가 이미 있으면 덮어쓰도록 해서 **몇 번 돌려도 같다.**

**한 마리는 그대로 죽이고, 한 마리는 `Initialize(data, isElite:true)` 로 재초기화한 뒤 죽였다.**


**같은 프레임에 두 클립이 동시에 물렸다.** 한쪽만 봤으면 분기가 죽어 있어도 통과했을 것이다
(30차 교훈 125 — "값이 안 바뀐다"는 그 자체로 아무것도 증명하지 못한다).

## 🔴 판정 ③⑤ 를 못 한 이유 — 이 머신은 게임이 무음이다

검증 중에 발견했다. **버그가 아니라 저장된 설정이다.**

```
[D8] 저장된 설정 bgm_vol=0.00 sfx_vol=0.00
```

`AudioManager.PlaySfx()`(`AudioManager.cs:158`)는 `SfxVolume <= 0f` 이면
**보이스에 클립을 물리기도 전에 return** 한다. 그래서 처음 검증에서 6개가 전부
`(못 찾음)` 으로 나왔고 **배선이 통째로 실패한 것처럼 보였다.**

검증만 통과시키려고 런타임에서 `am.SetSFXVolume(1f)` 를 호출했다 —
`SetSFXVolume` 은 `PlayerPrefs` 를 건드리지 않으므로(`AudioManager.cs:96~105`)
**사용자 설정을 바꾸지 않는다.**

→ 요청서 판정 ③⑤ 는 *"소리로 판정한다. 로그로는 안 된다"* 인데
**지금 설정으로는 사용자도 아무것도 들을 수 없다.**
옵션에서 볼륨을 올린 뒤에 들어 봐야 한다. `TUNING.md` 항목으로 넘겼다.
