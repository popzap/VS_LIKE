## 2. 🔑 두 번 다 **"만들지 않는 쪽"이 답이었다**

### ① 아이콘 7장 중 **6장은 안 그렸다**

강화 7종 중 6종이 패시브와 **같은 스탯**이다
(`MaxHp`·`Damage`·`PickupRadius`·`XpGain`·`Armor`·`MoveSpeed`).
다른 그림을 쓰면 같은 스탯이 화면에서 둘로 보인다 — **오히려 헷갈린다.**

**재사용이 되는지는 실측하고 나서 결정했다.** 패시브 11장 전부
**모서리 알파 0** 이고 반투명이 글로우 halo(0~10 %)뿐이라 `I-41` 가짜 투명이 아니었다.
안 재고 "아이콘이니 되겠지"로 넘어갔으면 회색 사각형 6개가 붙었을 자리다.

남은 `CritMultiplier` 하나만 새로 그렸다.
🔴 **`CritChance.png` 을 돌려 쓰지 않았다** — 그건 다른 스탯이고 이미 `CritChance` 패시브가 쓴다.
같은 그림이면 "치명 **확률**"과 "치명 **배수**"가 구분되지 않는다.
의미로 갈랐다 — CritChance = **맞히는 것**(과녁+단검), Precision = **크게 터지는 것**(폭발 별 + 조준 링).
색도 갈랐다(기존 치명·공격 계열이 빨강이라 이쪽은 금색).

### ② 승급과 레벨업에 그림을 **따로 안 만들었다**

둘은 **크기와 색만 다르면** 구분된다. 흰색 링·별 2장을 만들고 색은 프리팹이 정하게 했다 —
승급 금색·크게(링 3겹), 레벨업 청록·작게(링 2겹).
`C33` 의 UI 프레임, `C30` 의 예고 원과 **같은 방식**이다.

## 3. 승급에 연출이 0 이었다 — 비중이 거꾸로다

`EvolutionManager` 에 이펙트·파티클·흔들림 호출이 **하나도 없다.**

| | 있는 것 |
|---|---|
| 보스 **등장** | 화면 흔들림 `0.55 / 0.7` |
| 엘리트 **처치** | 히트스톱 |
| **승급** | 🔴 **없음** |

`I-57` 이 겉모습(초상·걷기)은 바꿔 놨지만 **바뀌는 순간**은 여전히 조용하다.
이 게임에서 가장 큰 성취인데 보스가 걸어 나오는 것보다 조용하다.

⇒ 요청-26 으로 넘겼다. **코드는 3줄**(`Instantiate`)뿐이고
`levelUpEffect` 쪽은 `HUDManager.cs:279` 가 **이미 다 돼 있어 꽂기만 하면 된다.**

> ⚠️ **방식은 안 정했다.** `[SerializeField]` 로 받을지 다른 경로로 받을지는 DEV 판단이고,
> 화면 흔들림을 같이 넣을지도 그렇다. **내가 정할 것은 그림과 "얼마나 커야 하는가"의 판정 기준**이고,
> 후자는 `TUNING.md` §D 에 *"보스 등장 0.55 와 엘리트 처치 0.20 사이 어디쯤인가"* 로 적었다.

## 4. 🟡 링을 한 번 다시 그렸다 — **두께가 얇아야 링이다**

첫 판은 띠 폭을 `0.62~0.97`(0.35)로 잡았다. 결과는 **퍼져 나가는 테두리가 아니라 뭉친 원반**이었다.
겹쳐 놓으니 가운데가 메워져 캐릭터를 덮었다.

폭을 `0.87~0.99`(**0.12**, 1/3)로 줄이고 **바깥 끝 0.012 를 완전 불투명**으로 박으니
그제서야 충격파로 읽혔다.

🔑 **두꺼운 링은 도넛이고, 도넛은 안 퍼진다.** 퍼지는 느낌은 *바깥이 날카롭고 안이 비어 있는 것*에서 온다.

🟡 **`BossSlamRing.png` 을 재사용하지 않은 이유도 같다** — 그건 바닥 예고라
테두리가 굵고 안쪽이 차 있고 조준 눈금이 있다. **역할이 반대라 모양도 반대여야 했다.**

## 5. 남긴 것

- 🔴 **"몇 장 필요한가"를 세기 전에 "몇 장 안 그려도 되는가"를 센다.**
  7장 요청에서 실제로 그린 건 **1장**이고, 연출 2종에서 그린 건 **2장**이다.
  겹치는 의미를 찾는 게 그리는 것보다 싸고, 결과도 더 일관된다
- **재사용은 "될 것 같다"가 아니라 재고 나서 정한다.** 패시브 11장의 알파를 안 봤으면
  `I-41` 짜리 6장을 그대로 붙일 뻔했다
- **역할이 반대면 모양도 반대다.** 예고 원과 충격파 링은 둘 다 "원"이지만
  하나는 *여기가 위험하다*(굵고 차 있다), 하나는 *지나갔다*(얇고 비었다)를 말한다.
  같은 파일로 때우려 했으면 둘 다 틀렸을 것이다
- **내가 정할 것과 아닌 것을 나눠 적었다.** 그림과 판정 기준은 내 것이고,
  프리팹 참조를 어떻게 받을지·흔들림을 넣을지는 DEV 것이다.
