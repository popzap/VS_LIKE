## 1. 🔴 35초 곡이 아니라 **2.4초 스팅어**로 답했다

`D83` 이 *"곡이 어려우면 스팅어도 **효과의 절반**은 난다"* 며 대안을 줬는데,
**이 불만에 한해서는 절반이 아니라 정답 쪽**이라고 판단했다.

사용자 말은 *"이벤트인지 **몰랐어**"* 다. 데이터는 요구대로였고 사용자도 *"짧고 빽빽했다"* 고 답했다.
빠진 건 **"지금이 이벤트다"라는 신호**다.

⇒ **인지(recognition) 문제**고, **인지는 시작 순간에 결정된다.**
35초 곡은 *분위기*를 더하는 것이라 그다음이다. 게다가 마감이 내일이라 **35초를 검증할 시간이 없다.**

🔑 **"곡이 어려우면 대안"이 아니라 "이 문제엔 이쪽이 맞다"** 로 답했다.
싸서 고른 게 아니라 **불만의 성질을 보고** 고른 것이다.

## 2. 🔴 `BossAppear` 와 대역이 겹쳤다 — 뜻으로 갈랐다

첫 판을 저역 위주로 만들었더니:

```
AmbushStart  0-200Hz 92.3%      BossAppear  0-200Hz 98.5%
```

**둘 다 "사건 알림"이라 자리가 가깝다.** 그냥 두면 안 갈린다.

⇒ **뜻으로 갈랐다: 보스 등장 = 무게(저역) · 기습 = 경보(중고역).**
**재앙은 낮고 경보는 높다.** 층을 전부 한 옥타브 이상 올리고 럼블을 잘라냈다.

| | 0-200 | 200-800 | 800-3k | 3k-9k |
|---|---:|---:|---:|---:|
| **AmbushStart** | **2.8 %** | **94.4 %** | 2.1 % | 0.7 % |
| BossAppear | **98.5 %** | 1.4 % | 0.1 % | 0.0 % |

**거의 상보적이다.**

🔑 **대역이 겹친다는 건 "둘 다 중요하다"는 뜻이 아니라 "하나를 못 듣는다"는 뜻이다.**
`C33`(탄환 실루엣)·`C47`(아이콘 실루엣)과 같은 문제를 **소리에서** 만난 것이다 —
**색·모양·대역, 축은 달라도 "겹치면 못 가른다"는 같다.**

## 3. 🟡 100마리가 쏟아지는 순간에 울린다

`EnemyHit` 이 그때 초당 수십 번 난다. 재 봤다:

```
EnemyHit     0-200 34.2% / 200-800 31.8% / 800-3k 23.9% / 3k-9k 9.7%   (광대역)
AmbushStart  200-800 에 94.4% 집중
```

**대역은 겹친다.** 그런데 성격이 다르다 —
`EnemyHit` 은 **순간음**, 스팅어는 **2.4초 지속되는 사이렌**이다.
**버티는 소리가 튀는 소리들을 뚫는다.** 그게 두 번째 분리 축이다.

그래도 볼륨이 낮으면 묻히므로 권장값을 같이 줬다 —
`Volume 0.90`(`BossAppear` 0.95 바로 아래) · `PitchJitter 0`.
🔑 **신호음은 매번 똑같아야 사건으로 느껴진다** (`BossAppear`·`WaveClear`·`LevelUp` 전부 0 이다).

| | 결과 |
|---|---|

| `alpha (255,255)` | 🟢 **`I-41` 이 아니다** — 배경까지 그린 **일러스트**라 불투명이 맞다 |

🔑 **"수상하다"를 세 개 들고 갔는데 둘이 틀렸다.** 눈으로 열어 보고 저장소 통계를 냈더니
과장이었다. **보내기 전에 재는 것이 두 번의 헛경보를 막았다.**

🟡 남는 건 파일명 오타(`Kepper` → `Keeper`)뿐인데 **급하지 않다** —
처음엔 *"지금 안 고치면 참조가 끊긴다"* 고 생각했지만 **guid 는 `.meta` 에 있어서
파일+메타를 같이 옮기면 안 끊긴다.** 그것도 내가 틀렸다.

ℹ️ 내가 만든 픽셀아트 `ShopKeeper.png`(C35/D42)는 **이제 참조 0곳**이다 —
사용자가 일러스트를 고른 결과라 **그게 맞다.** 안 지운다.

## 6. 남긴 것

- 🔑 **대안이 싸다고 고르는 게 아니라 문제의 성질을 보고 고른다.**
  *"곡이 어려우면 스팅어"* 가 아니라 *"'몰랐다'는 인지 문제니 스팅어"* 다.
  같은 결론이라도 **근거가 다르면 다음 판단이 달라진다**
- 🔴 **겹치면 못 가른다 — 축이 무엇이든.** 탄환은 실루엣(`C33`), 아이콘은 실루엣+색(`C47`),
  소리는 **대역**이었다. 매번 *"둘 다 중요한데 같아 보인다"* 로 시작해서
  **"뜻으로 갈라라"** 로 끝난다
- **버티는 소리가 튀는 소리를 뚫는다.** 대역이 겹쳐도 **지속 시간**이 분리 축이 된다.
  대역만 보고 포기했으면 200-800Hz 를 통째로 피하느라 소리가 이상해졌을 것이다
- 🟢 **의심 셋 중 둘이 틀렸고, 그걸 보내기 전에 알았다.** 파일을 열어 보고 통계를 냈다.
  **헛경보도 비용이다** — 상대가 확인하는 시간을 쓴다
