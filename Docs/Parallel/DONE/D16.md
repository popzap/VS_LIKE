## 왜 했나

두 요청이 **같은 무기 2종을 각각 반쪽씩** 다루고 있어서 하나로 묶었다.

| | 요청-13 (C19) | 요청-14 (C20) |
|---|---|---|
| 무엇 | 소환수 2종을 CSV 로 게임에 올린다 + 촉수 그림 교체 | 소환수 2종에 제 효과음을 준다 |
| 없으면 | 프리팹·코드는 다 있는데 **레벨업 카드에 안 뜬다** | 화염구=`WeaponCast`(마법 시전음) · 촉수=`WeaponFire`(**총소리**) |

"문어가 후린다"가 아니라 "문어가 사라졌다"로 보였다.

### 임포트 규격을 또 손으로 맞췄다

D8 · D14 와 **똑같은 함정**. Refresh 직후 두 wav 는 `compressionFormat: 1`(Vorbis) ·
스테레오로 들어온다. `AudioImporter` 를 세팅하고 `SaveAndReimport()` 했다.

```
loadType 0 · compressionFormat 2(ADPCM) · quality 1 · 44100 · preloadAudioData 0
forceToMono 1 · normalize 1 · 3D 1
```

실측 결과 두 클립 모두 `ch=1 hz=44100 fmt=ADPCM load=DecompressOnLoad forceToMono=1`,
길이 **0.280s**(촉수) · **0.221s**(드래곤). `.meta` 가 `SFX_ToxinSpill.wav.meta` 와 형태가 같다.

> 🔴 **`AudioImporter.preloadAudioData` 는 Unity 6.3 에서 obsolete 다** (`CS0619` = 컴파일 에러).
> `ai.defaultSampleSettings.preloadAudioData` 로 옮겨졌다. `RunCommand` 안에서 옛 이름을
> 쓰면 스크립트가 통째로 안 돈다.

## 어떻게 확인했나

### 임시 프로브 — `AudioManager.PlaySfx(SfxId)` 안 (**삭제됨**)

D14 와 같은 이유로 **대조군을 같이 셌다.** 새 소리가 난다는 것만으로는
**옛 소리가 같이 나는지**를 알 수 없다.

Warrior 로 한 판 돌리며 소환수 2종을 레벨업 카드로 받아 약 40초 관찰:

```
[SFXPROBE] 집계 46건 — DragonSpit=17  TentacleLash=15  WeaponSwing=14
                        대조 WeaponFire=0  WeaponCast=0
```

- 드래곤 발사 간격 = **정확히 1.4s** (Lv1 쿨다운), 한 번도 거르지 않았다
- 촉수 간격 = **1.2s**, 중간에 2.4s 공백이 몇 번 → `FireRing` 이 사거리에 적이 없어
  **조용히 돌아간 것**이다 (허공을 후리지 않는다 = 설계대로)

### 촉수 그림 실측 (6프레임)

```
        바깥지름   중앙 구멍   잉크 비율
f0      45.49px    12.65px    2.3%
f1      73.59px    13.60px    3.6%
f2      94.02px    14.56px    4.5%
f3      99.85px    15.52px    4.6%   <- 최대
f4      97.49px    16.12px    3.7%
f5      80.65px    16.97px    2.3%

중심 r<=12px 불투명 픽셀 = 0  (6프레임 전부)
```

정지 상태에서 판정하려고 **`timeScale = 0` 으로 세워 놓고 찍었다** —
쿨다운 1.2s 에 FX 는 0.2s 라 실플레이 중에는 프레임을 잡을 수 없다.
카메라를 문어에 붙이고(`orthographicSize 1.6`) `TentacleLash_3` 을 스케일 1.809 로
띄운 뒤 캡처하고 즉시 파괴했다.

## 알게 된 것

### 🔴 촉수 클립은 코드 상수에 묶여 있다

소리는 `Fire()` 시점(t=0)에 나고 피해는 `lashHitDelay` **0.1s** 뒤에 들어간다.
클립은 그 0.1s 지점에 타격 피크가 오도록 구워져 있다.
**`SummonWeapon.lashHitDelay` 를 바꾸면 `Tools/Audio/gen_tentacle_lash.py` 의 `HIT_AT` 도
같이 바꿔 다시 구워야 한다.** 잊으면 "휘두른 뒤 한참 있다 맞는" 소리가 된다.
코드와 `AudioId.cs` 양쪽에 경고 주석을 박아 뒀다.

### 링 반경이 소환수 오프셋보다 커서 플레이어를 덮는다

Lv1 `Range 1.8` · `offsetDistance 1.2` → **플레이어가 링 안에 들어온다.**
실제로 촉수가 기사 스프라이트 **위를 지나가는 것을 눈으로 확인했다.**
요청-13 "같이 남겨 줄 것" 3번(플레이어 가림)의 **직접 증거**다.
Lv5 는 `Range 2.6` 이라 더 심해진다. 판정은 CONTENT 몫.

### 자동 플레이로 판정하려면 두 관문을 넘어야 한다

1. `StartRun()` 은 웨이브가 아니라 **`GameState.StageMap`** 으로 간다 —
   `StageMapManager.SelectNode(map.Layers[0][0])` 를 한 번 더 불러야 웨이브가 시작된다
2. 레벨업이 뜨면 `timeScale = 0` 이라 **게임 시간이 안 흐른다** —
   `LevelUpManager.SelectItem(...)` 으로 계속 치워 줘야 관찰이 이어진다
