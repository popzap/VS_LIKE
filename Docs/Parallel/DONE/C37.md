## 1. 🔴 받은 선택지 셋이 다 안 맞았다

`D49` 가 층 테마를 배선했는데 화면이 **1.4 %** 밖에 안 달라진다며 셋 중 고르라고 했다 —
**A** 기존 10장의 명도를 벌린다 · **B** 깊은 층 전용 타일을 새로 만든다 · **C** 그대로 둔다.

**재 봤더니 A·B 는 헛수고다.**

| 타일 | 원본 밝기 | `m_Color` 배율 | **화면 밝기** |
|---|---:|---:|---:|
| Grass | 0.154 | 0.94 | **0.156** |
| MossyCobble | 0.142 | 0.96 | **0.156** |
| StoneSlab | 0.282 | 0.51 | **0.157** |
| Flagstone | **0.318** | **0.45** | **0.157** |

**원본 밝기 폭이 0.175 인데 화면에서는 10종 전부 `(0.154, 0.166, 0.115)` · `0.156 ± 0.002` 다.**
`I-28`(퀼트 제거)의 평준화가 **밝을수록 더 깎아서** 한 점으로 모은다.

⇒ PNG 를 다시 칠하든 새로 그리든 **평준화가 또 한 점으로 끌어내린다.**
🔑 **손잡이는 PNG 가 아니라 `m_Color` 였다.**

`D49` 의 화면 실측(`0.1510 → 0.1447`)도 이걸로 설명된다 —
내가 타일 평균으로 계산한 순수 예측치는 **`dL 0.0001`** 이다.

## 2. ✅ 안 D — **한 점이 아니라 램프로 평준화한다**

🔑 **`I-28` 과 `D49` 는 같은 손잡이를 반대로 당기는 게 아니었다.**

| | 없애려는 것 |
|---|---|
| `I-28` | *한 층 안에서* **이웃 타일이** 달라 보이는 퀼트 |
| `D49` | *층과 층 사이가* **안** 달라 보이는 것 |

**같이 깔리는 타일끼리만 같으면 둘 다 만족한다.**
`GroundTiler.tiles` 가 이미 얕은 것 → 깊은 것 순이라 **그 인덱스를 따라 목표색을 이으면** 된다.

```
Grass      (0.150, 0.180, 0.108)  L 0.163   따뜻한 풀색
   …                램프 (감마 1.6)
Flagstone  (0.080, 0.090, 0.125)  L 0.091   차가운 청회색
```

| | 층0 | 층9 | **dL** |
|---|---:|---:|---:|
| 지금 | 0.1563 | 0.1564 | **0.0001** |
| 바꾼 뒤 | **0.1542** | **0.1098** | **0.0443** ✅ |

**층0 밝기가 거의 안 움직인다.** 배율은 `Color32` 라 1을 못 넘어 밝히는 쪽 조정이 안 되므로
**얕은 쪽은 지금을 지키고 깊은 쪽만 내렸다.** 초반이 어두워지면 안 된다.

## 3. 🟡 두 무리로 끊었다가 되돌렸다 — 퀼트가 일부 돌아왔다

처음엔 얕은 4종 / 깊은 4종을 각각 **한 점**에 모았다. 층 구분은 더 컸다(**dL 0.0533**).
그런데 화면을 그려 보니 **얕은 층에 짙은 파랑 조각이 구멍처럼 튀었다** —
층0 에서도 깊은 타일이 **7 %** 는 깔리는데 그게 가장 먼 색이기 때문이다.
**`I-28` 이 없애려던 바로 그 문제를 내가 다시 만든 것이다.**

램프로 이으니 이웃한 가중치의 타일이 이웃한 색을 갖는다:

| | dL | 층0 편차(=퀼트 세기) |
|---|---:|---:|
| 두 무리 | 0.0533 | 0.0215 |
| 램프 γ1.0 | 0.0438 | 0.0168 |
| **램프 γ1.6** | **0.0443** | **0.0138** ← 채택 |
| 램프 γ2.2 | 0.0434 | 0.0120 (층9 편차는 0.0231 로 오른다) |

**층 구분 0.009 를 내주고 퀼트를 36 % 줄였다.** 통과선(0.04)은 여전히 넘는다.

**셋 다 세 층 모두에서 읽힌다.** 청록 예광탄은 오히려 깊은 층에서 더 또렷하다.

## 5. 남긴 것

- 🔴 **"비슷해 보인다"의 원인이 그림에 있다고 단정하지 않는다.** 타일은 안 비슷했다 —
  **중간에서 뭉개는 것**이 있었다. 원본을 재고 화면값을 따로 재서 **둘을 비교해야** 보인다.
  안 쟀으면 타일 10장을 다시 칠하고도 `dL` 이 그대로였을 것이다
- 🔑 **부딪혀 보이는 두 요구가 실제로는 안 부딪힐 수 있다.** `I-28`(퀼트 없애기)과
  `D49`(층 구분하기)는 "타일이 서로 같아야 하나 달라야 하나"로 보이지만,
  **"언제 같이 깔리나"를 넣으면 둘 다 만족하는 답이 있다.**
  선택지가 A·B·C 로 왔을 때 **넷째가 있는지 보는 값**이 여기서 나왔다
- **되돌린 것도 기록한다.** 두 무리 안은 숫자(dL)로는 더 좋았는데 **그려 보니 틀렸다.**
  통과선만 보고 골랐으면 퀼트를 되살렸을 것이다 — **판정 기준이 하나면 그 기준 밖으로 넘친다**
