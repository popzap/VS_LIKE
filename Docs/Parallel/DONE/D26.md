## 🟡 함정 — 유효 `maxTextureSize` 는 `.meta` 최상단에 없다

`.meta` 최상단의 `maxTextureSize: 2048` 을 읽고 "초상은 2048" 이라고 답했다가 틀렸다.
실제로 적용되는 값은 `platformSettings[buildTarget: DefaultTexturePlatform]` 안에 있고 **512** 다
(그래서 1024² 원본이 512px 로 로드된다). 코드에서는 이렇게 접근한다:

```csharp
var ps = ti.GetDefaultPlatformTextureSettings();
ps.maxTextureSize     = 512;
ps.textureCompression = TextureImporterCompression.Uncompressed;
ti.SetPlatformTextureSettings(ps);
```
