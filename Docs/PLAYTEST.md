## 판 A — 아무 직업, 한 판 (제일 값이 큼)

🔴 **Dev 패널(백틱 `` ` ``)을 쓰지 말 것.** `Run Gold +100`·`Level +1` 을 누르면 이 판이 무의미해진다.
**죽어도 된다.** 중도 사망도 유효한 데이터다.

### A-0. 🔴 딱 하나만 해도 된다면 이것

판이 끝나면 Console 에 이 줄이 뜬다:

```
[GameManager] 런 정산 — 메타 골드 +N · 남은 런 골드 M 소멸
```

- [ ] **M = ______**

> 통과선 **M ≤ 300**. DEV 예측은 **M ≈ 600** 이다(수입 이론 최대 1757G vs 배수구 241G).
> 예측대로면 `weightShop 0.15 → 0.28` · `shopSlotCount 3 → 4` 로 배수구를 넓힌다.
